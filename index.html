关于本站

本站通过浏览器 Web Bluetooth 直连支持标准 BLE 心率服务 （0x180D）的设备，实时绘制滚动心电图。每次心搏都会在 R 峰位置 迸发一簇粒子，并点亮信号指示灯。

未连接设备时自动进入模拟模式，拖动底部的速度滑块可改变运动强度， 心率会随强度平滑上升并带轻微波动，适合演示与调试。

兼容设备

只要设备支持标准 BLE 心率服务（0x180D）即可连接。部分手表/手环需先在设备端 手动开启「心率广播」或「心率推送」功能，浏览器才能搜索到。

使用说明
User Guide

快速开始

1. 用 Chrome 或 Edge 打开页面（HTTPS 或 localhost）
2. 点击底部「连接心率设备」，选择你的设备
3. 连接成功后，心电图会实时显示心率，每次心搏触发粒子迸发与信号灯闪烁
4. 未连接设备时，拖动「速度」滑块即可模拟 68–180 BPM

粒子效果

启用粒子：控制心跳时是否迸发粒子。
全屏粒子：开启后，粒子会铺满整个屏幕，不再只集中在 R 峰。
粒子强度：控制粒子的基础数量倍数（标准 / 丰富 / 爆炸 / 狂野）。
粒子颜色：点击色块切换粒子颜色。
摆动方向：控制粒子的初速度方向。自由扩散是四散；向上/下/左/右是定向；顺时针/逆时针带切向旋转。

心率曲线

局部放大：在屏幕右下角显示一个放大窗口，展示最近一个完整心搏的波形。
手动打点标记：开启后，点击波形区域会在该位置添加一个运动节点标记（白色竖线 + 圆点）。标记会随波形一起滚动。

信号提示

心跳信号灯：位于顶部 BPM 数字下方，是一个会扩散脉冲的圆环。每次心搏时，圆环向外扩散并淡出，用来直观确认信号正在被接收。

清除标记

在设置面板点「清除所有标记」，会移除当前所有打点标记。

面板操作

· 点击右上角「设置」/「关于」切换面板
· 点击面板外空白区域或按 ESC 关闭当前面板

浏览器要求

Chrome / Edge 等 Chromium 内核浏览器，页面运行在 HTTPS 或 localhost 下。Safari、Firefox 暂不支持 Web Bluetooth。
